
# Personal Expense Data Analysis

## Project Description
This project analyses personal expenses using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Features
- Reads expense data from CSV
- Calculates total expenses
- Calculates average expenses
- Groups expenses by category
- Creates bar charts
- Creates pie charts

## Project Files
- analysis.py: Main Python program
- expenses.csv: Sample expense dataset
- expenses_bar_chart.png: Bar chart
- expenses_pie_chart.png: Pie chart

## How to Run

Install the required libraries:

pip install pandas matplotlib

Run the program:

python analysis.py
